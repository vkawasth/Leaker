This data shows midbrain isolation that regulates consciousness. (reference https://www.physio-pedia.com/Middle_Cerebral_Artery)
The Midbrain (MB) is the core of the Ascending Reticular Activating System (ARAS) — the brain’s physical “on/off” switch for consciousness. Seeing a shift in this specific region when transitioning from hyperactivity to coma is the fundamental neurobiological marker of arousal state changes.

Coarsened Brain looks as follows (only 1% nodes and vessels), as you can see nothing gets completly eliminated during this coarsening (green dots are basal ganglia and visual, auditory hippocampus regions are all reduced to their 1% representation). GV/BV flows select high probability nodes/edges, apply hochschild cochains based compression, upto degree 2 (deformation theory) and then blow out 70% low probability nodes thus generating a brain for low power low data algebraic analysis, while keeping all data structures which played key role during the evolution of a given outcome from start to finish during entire simulation. Final coarsed data is 1.2 GB, simulation runs for 600 epochs and at the end of each epoch, saving eveything takes 1.7 GB (pre blow out network), so blow out removed the need to save 600*1.7 GB of data and all the post analysis that should have been performed to isolate key contriobuting structures.
